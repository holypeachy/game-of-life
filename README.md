# Conway's Game of Life

A small interactive implementation of Conway's Game of Life built with C# and Raylib.

**Built with:** C# | Raylib-cs | .NET 6

## Overview

I learned about Raylib for C# and used it to build an interactive version of Conway's Game of Life. It is still one of my favorite small projects. Although I cringe when I look back on the code.

The simulation runs on a grid that wraps in every direction, allowing cells and patterns to cross an edge and continue from the opposite side.

## Features

- Place and remove cells by clicking the grid.
- Run or pause the simulation and advance it one generation at a time.
- Randomize or clear the grid.
- Save and load the current grid state.
- Track the current generation.
- Adjust the grid size and update interval in the source.
